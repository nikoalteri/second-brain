## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Sanctum client → `/api/v1/*` | Authenticated but untrusted; tenant identity must come from `$request->user()`, never request input |
| Panel user → `/admin/*` | Authenticated panel user, possibly non-superadmin; Filament route model binding must not resolve foreign records |
| Controller/Resource → Eloquent | Every `withoutGlobalScopes()` call removes the tenant boundary and must re-apply its own gate |
