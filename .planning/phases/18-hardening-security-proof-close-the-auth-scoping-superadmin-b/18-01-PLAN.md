<objective>
Close the confirmed cross-user data disclosure in the `transactionCategories` GraphQL query.

Purpose: `app/GraphQL/Queries/TransactionCategories.php` calls `TransactionCategory::withoutGlobalScopes()` with zero user or role gating, returning every user's category tree to any authenticated caller. `TransactionCategory` uses `HasUserScoping`, has a **non-nullable** `user_id` foreign key (`database/migrations/2026_02_21_133504_create_transaction_categories_table.php:16`) and a `unique(['user_id', 'name', 'parent_id'])` constraint — it is unambiguously a per-user model, not a shared taxonomy. The existing test `test_graphql_transaction_categories_query_returns_shared_categories` locks the leak in as if it were intended; the test is wrong, not the model. Category names leak spending-habit structure across tenants, meeting D-02's "high severity → fix in this phase" bar.

Note: RESEARCH.md Pitfall 3 and Assumption A2 recommended treating this as intended design pending user confirmation. The user has since explicitly confirmed it is a REAL BUG. Fix it (per D-02/D-03); do not re-open the question.

Output: Owner-scoped resolver with superadmin bypass, corrected schema description, and regression tests proving isolation for both GraphQL category surfaces (`transactionCategories` and D-05's `totalByCategory` site).
</objective>

```php
public function __invoke(mixed $root, array $args, GraphQLContext $context, ResolveInfo $info)
{
    $user = $context->user();
    $isSuperadmin = $user->hasRole('superadmin');

    return TransactionCategory::withoutGlobalScopes()
        ->with([
            'parent' => fn ($query) => $query
                ->withoutGlobalScopes()
                ->when(
                    ! $isSuperadmin,
                    fn ($parentQuery) => $parentQuery->where('transaction_categories.user_id', $user->id)
                ),
        ])
        ->when(
            ! $isSuperadmin,
            fn ($query) => $query->where('transaction_categories.user_id', $user->id)
        )
        ->where('is_active', true)
        ->orderBy('parent_id')
        ->orderBy('name')
        ->get();
}
```
