# Plan 25-04 — SPA import flow and verification

## Objective

Give users the upload → mapping → review → confirm flow in the SPA.

## Read first

`25-RESEARCH.md`, `25-03-SUMMARY.md`, `TransactionsView.vue`, `TransactionFormView.vue`, the router, `useCurrency.js`, the Phase 24 store/session-guard pattern and Vitest setup (`tests/Frontend/*.spec.js`).

## Work

1. Pinia store with a session guard (reset on logout) and views: pick target and file (optional ending balance), column mapping with preview and parsing options, review table with duplicate/look-alike badges, edit/discard, confirm selected or all, per-row outcomes.
2. Amounts via `formatCurrency(amount, currency)`; clear states for loading, error, empty, partial confirmation.
3. Vitest component/store tests; `npm run build`.
4. Full backend suite; browser check at desktop and mobile with synthetic data only. Never use the real statements under `.planning/` or `tmp/pdfs/`.

## Acceptance

A user can import a CSV for an account and for a card, see and resolve duplicates, and confirm; nothing is posted before confirmation.

## Output

`25-04-SUMMARY.md` with UI states, evidence, and any unchecked visual follow-up recorded separately.
