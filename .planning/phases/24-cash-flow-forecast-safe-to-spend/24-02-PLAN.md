# Plan 24-02 — forecast arithmetic and dashboard API

## Objective

Turn the classified obligations into an honest per-currency estimate and expose it through the authenticated dashboard API.

## Read first

`24-CONTEXT.md`, `24-RESEARCH.md`, `24-01-SUMMARY.md`, `Account`, `SavingGoal`, `DashboardController`, `routes/api.php`, `DashboardApiTest`.

## Work

1. Query only the authenticated owner's active accounts and active goal-linked account IDs. Exclude each entire goal-linked account. Group the included balances by currency, retaining excluded-account counts and unknown-currency coverage. Do not rely on the Dashboard's current client-side balance sum or superadmin bypass scopes.
2. Sum only obligations that represent future debits from included accounts, once per identity, per currency. Use decimal-safe arithmetic (integer minor units or decimal strings); do not add currencies together. Return negative estimates when known commitments exceed available balance, rather than clamping to zero. Keep item-level reason codes for zero-contribution and excluded obligations.
3. Add `GET /api/v1/dashboard/cash-flow-forecast` returning `as_of`, `through_date`, `horizon_days: 30`, per-currency balance/commitments/estimated remainder, obligation breakdown and coverage flags/counts. The estimate must be marked incomplete for overdue items, unknown source/currency, unsupported card settlement and bank data not reconciled by an import. Avoid exposing names or IDs from another owner.
4. Add feature tests for single and mixed currencies, full goal-account exclusion, inactive accounts, existing posting, overdue coverage, zero balance, negative result, superadmin personal scope and unauthorized access. Ensure the existing dashboard endpoints remain unchanged.

## Acceptance and verification

- An EUR account and a USD account yield two separately labelled estimates; there is no all-currency scalar.
- The API explains the amount deducted and every material coverage gap. It never labels a partial estimate complete.
- Run the relevant feature tests and full backend suite. Inspect the JSON shape for future Phase 26 dashboard coexistence.

## Output

Create `24-02-SUMMARY.md` with response example, arithmetic proof and test results.
